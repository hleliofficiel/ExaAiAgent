# ExaAiAgent Contributor Badges

Vector (SVG) achievement badges for the ExaAiAgent Contributor Achievement
System. All badges share a unified metallic identity: dark plate, colored
metal ring (radial gradient), laurel wreath, medal star, and a ribbon with the
ALL-CAPS badge name. Backgrounds are **transparent** — safe to embed anywhere.

These are simplified vector homages to the reference artwork; they are not
pixel-perfect reproductions of the JPG concept art.

## Files

| File | Badge |
| --- | --- |
| `first_contributor.svg` | First Contributor (copper) |
| `code_contributor.svg` | Code Contributor (blue/silver) |
| `bug_hunter.svg` | Bug Hunter (gold) |
| `documentation_hero.svg` | Documentation Hero (emerald) |
| `feature_builder.svg` | Feature Builder (purple) |
| `testing_champion.svg` | Testing Champion (cyan) |
| `top_contributor.svg` | Top Contributor (red) |
| `core_maintainer.svg` | Core Maintainer (platinum, manual grant) |
| `community_hero.svg` | Community Hero (rose) |
| `open_source_advocate.svg` | Open Source Advocate (lime/anthracite gold) |

All SVGs use `viewBox="0 0 512 640"`, carry a `<title>`, and have no
background fill.

## Embed in a profile README

```html
<img src="https://github.com/hleliofficiel/ExaAiAgent/raw/main/contributor_system/badges/first_contributor.svg" width="128" alt="First Contributor" />
```

or Markdown:

```markdown
![First Contributor](https://github.com/hleliofficiel/ExaAiAgent/raw/main/contributor_system/badges/first_contributor.svg)
```

Generate embeds for badges you have actually earned:

```bash
exaai contributors export <your-login>
```

See `docs/contributor-achievements.md` for the full criteria, levels and CLI.
