# CVE Intelligence Pipeline
Sources (all free, no API keys except optional GitHub token): FIRST EPSS (daily probability + percentile), CISA KEV (known exploited, BOD deadlines), OSV.dev (package vulns, GHSA mirror), GitHub Advisories REST. Module: `exaaiagnt/intelligence/` (`fetch_epss`, `fetch_kev`, `fetch_osv`, `CVEIntelPipeline.enrich`). Priority: KEV=100, else `percentile*70 + epss*30 + cvss*0.5` (clamped 0-100, tested in `tests/intelligence/`). Offline-safe: fields stay unknown on network failure — never invented. Provenance (`sources`, `fetched_at`) is stored on every record.
